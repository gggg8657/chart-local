샘플:
열 머리글에서 이름·타입(숫자·날짜·기간·범주)·단위를 고칠 수 있습니다. 천단위 쉼표·%·괄호 음수·단위 행은 자동 처리됩니다.

2그래프 후보

3편집

4문서로 내보내기 받는 사람이 그 프로그램에서 값을 고칠 수 있게 차트 개체로 넣습니다

형식별로 무엇이 '고칠 수 있는' 상태로 들어가나요?
  • XLSX — '데이터' 시트(원본) + 그림마다 시트 하나. 그림 시트의 표는 데이터 시트를 가리키는 수식이고 차트는 엑셀 네이티브 차트라, 데이터 시트 값을 고치면 표와 차트가 함께 바뀝니다. 히스토그램은 COUNTIFS, 상자그림은 QUARTILE.INC 수식. 히트맵은 조건부 서식 색조.
  • PPTX — 그림마다 슬라이드 한 장, 파워포인트 네이티브 차트(내장 워크북 포함). 차트 오른쪽 클릭 → 데이터 편집.
  • DOCX — 워드 네이티브 차트(차트 파트 + 내장 워크북). 차트 오른쪽 클릭 → 데이터 편집. 아래에 데이터 표도 넣습니다.
  • HWPX — kordoc 으로 만든 한글 차트 개체 + 한글 표. 상자그림·히트맵·이중축은 kordoc 한글 차트가 그 형식(보조 축 등)을 지원하지 않아 그림(PNG) + 표로 넣습니다.
  • 이중축 — XLSX·PPTX·DOCX 는 왼쪽 축 막대(또는 선) + 오른쪽 축 꺾은선의 네이티브 콤보 차트(보조 세로 축). 축 제목은 계열 색, 범례에 '(오른쪽 축)'. 음수가 있으면 두 축의 0선이 맞도록 축 범위를 고정합니다.
  • 히트맵은 차트가 아니라 색을 칠한 표로 들어갑니다(PPTX·DOCX). 상자그림의 문서 차트는 수염을 최소~최대로 그립니다(이상값 표시 없음).

이력 표·후보·내보낸 파일이 이 서버의 도구 데이터 폴더에 남습니다
