# chart-local — 표 → 그래프 후보 갤러리 → 고칠 수 있는 문서(XLSX·PPTX·DOCX·HWPX)

엑셀에서 복사한 표(또는 CSV·XLSX)를 넣으면 데이터 모양에 맞는 그래프 후보 6~12개를 한꺼번에 그려 보여 주고, 고른 그래프를 **받는 사람이 그 프로그램에서 값을 고칠 수 있는 차트 개체**로 엑셀·파워포인트·워드·한글 문서에 담아 줍니다.

> ⚠️ 연구·내부 시험용 프로토타입입니다(배포·상업 서비스용 아님). 제3자 구성요소의 라이선스는 THIRD_PARTY_NOTICES.md 를 확인하세요.

![chart-local 그래프 후보 갤러리 — ① 추천 카드](docs/img/chart-gallery.png)

## 무엇을 하나

- 붙여넣기·CSV·XLSX를 파싱해 열 타입(연도·숫자·범주)과 단위를 추론하고, **규칙 엔진**이 어울리지 않는 차트는 빼고 후보를 만듭니다.
- 고른 차트를 편집(제목·축·색·범례·값 라벨·정렬·계열 on/off)한 뒤 XLSX·PPTX·DOCX·HWPX의 네이티브 차트 XML로 내보냅니다.
- 차트 숫자는 표에서만 읽습니다. 로컬 LLM 은 두 곳에만 씁니다 — (1) 후보마다 제목·한 줄 설명 문구(`api/describe`), (2) **AI 추천 순위·제안**(`api/rerank`): 규칙 후보 안에서 순서를 다시 매기고, 더 맞는 종류가 있으면 최대 3개 제안. 제안은 서버가 열·타입·부적합 조건을 검사하고 실제로 그려 본 것만 'AI 제안' 카드로 붙습니다. 표에 없는 숫자가 섞인 문장은 버립니다.
- LLM 이 없거나 느리거나 답이 틀려도 **규칙 추천만으로 그대로 동작**합니다(첫 화면은 늘 규칙 후보, AI 순위는 나중에 덧붙음).
- SVG 렌더러를 자체 구현해 CDN·외부 통신이 없습니다.

## 사용 방법

![데이터 넣기 — ① 붙여넣기 칸 ② 표 읽기](docs/img/chart-input.png)

1. **표 데이터를 넣는다** — ① 칸에 엑셀 표(머리글 포함)를 붙여 넣거나 CSV·XLSX를 올리고 ② **표 읽기**. 처음이면 **샘플**(연도별 예산·실험 측정값·부서별 비율·주가·역량 평가·월별 손익·채용 단계·목표 대비 실적·기준금리·시도별 지표·월별 운영 지표·월별 강수량·**주가 일봉 160일(가상 데이터)**) 버튼을 누르세요.
2. **파싱 후 추천을 본다** — 읽힌 표의 열 이름·타입·단위를 확인·수정하면, 데이터 모양에 맞는 후보 카드가 나옵니다(맨 위 화면 ①). 카드마다 '왜 이 그래프인지' 한 줄이 붙습니다. 잠시 뒤 로컬 LLM 이 **AI 추천 순위**로 카드를 다시 늘어놓고(배지·이유 한 줄), 더 맞는 그래프가 있으면 **AI 제안** 카드를 뒤에 붙입니다. **규칙 순서로** 를 누르면 원래 순서로 봅니다.
3. **카드를 고르고 편집한다** — 카드를 누르면 편집 탭으로 이동합니다.

   ![편집 — ① 큰 미리보기 ② 편집 패널](docs/img/chart-edit.png)

   ① 큰 미리보기에서 차트 유형·시리즈를 확인하고, ② 편집 패널에서 제목·범례·색·축 범위를 조정합니다. SVG/PNG로 바로 저장할 수도 있습니다.
4. **Office 문서로 저장한다** — 담을 카드의 **문서에 담기**를 체크(여러 개 가능)하고 엑셀 / 파워포인트 / 워드 / 한글 중 하나로 내려받습니다. 결과에는 그림마다 들어간 방식(네이티브 차트 / 색 칠한 표 / 그림+표)과 파일 구조 검사 결과가 표시됩니다.

## 예시

실제로 실행한 입력과 결과입니다(가상 데이터, 제목·설명 제안 gemma4:31b, 2026-10-12).

- **입력**(붙여넣기):

  ```
  2025 분기별 채널 이용자 수 (단위: 명)
  분기	웹	모바일	메신저
  1분기	1,240	2,310	860
  2분기	1,180	2,690	1,020
  3분기	1,090	3,050	1,310
  4분기	1,020	3,420	1,580
  ```
- **파싱**: 표 4행 × 4열, 첫 줄을 제목·단위(명)로 사용.
- **추천**: 후보 6개 — 꺾은선, 묶은 세로 막대, 누적 세로 막대, 세로 막대(웹), 누적 영역, 히트맵(위 갤러리 화면).
- **편집**: 누적 세로 막대를 골라 부제에 `출처: gggg8657 집계 · 2025년 기준`을 넣었습니다(편집 화면).
- **내보내기**: 문서 제목 `2025 채널 이용 현황 (gggg8657)`으로 PPTX — 네이티브 차트 1개, 구조 검사 통과.

## 설치·실행

```bash
bash setup.sh                 # Python → openpyxl·python-pptx·python-docx(없으면 venv) → kordoc 탐색(HWPX) → LLM 탐색(선택) → selftest → http://localhost:8786
bash setup.sh stop
python3 app.py                # 수동 실행
python3 app.py --cli 표.csv pptx 결과.pptx     # 추천 상위 4개를 문서로 (xlsx|pptx|docx|hwpx)
python3 selftest.py           # LLM 없이 검증 (WORKSPACE 를 임시 폴더로 바꿔 돌고 지움). SELFTEST_OUT=폴더 → SVG·문서 저장
```

## 구성
- `core.py` — 붙여넣기(탭)·CSV(cp949 포함)·XLSX(시트 선택) 읽기, 제목 줄·`(단위: 억원)` 줄·머리글·머리글 아래 단위 행·`예산(억원)` 처리,
  천단위 쉼표·`%`·괄호 음수·`△` 음수, 열 타입(숫자·날짜/기간·범주) 추론, 기간이 가로 머리글인 표 자동 전치, 긴 형식(연도·부서·값) 자동 피벗,
  **추천 규칙**, 차트용 데이터 준비(중복 x 합계/평균, 정렬, 상위 N)
- `fin.py` — 주가 지표(표준 라이브러리만): 이동평균·볼린저(모집단 표준편차)·EMA(SMA 시작)·MACD·와일더 RSI·매물대(저가~고가 고르게 배분, POC·가치 영역 70%)
- `svg.py` — 그래프 SVG 렌더러(미리보기·PNG·HWPX 그림 공통)
- `export.py` — 4개 형식 생성 + `verify()`(만든 파일을 다시 열어 구조 검사)
- `app.py` — stdlib HTTP, LLM 호출·숫자 거르기, 이력 · `ui.html` — 화면
- `rerank.py` — AI 추천 순위·제안: 표 요약(구분자로 감싼 데이터)·후보·허용 종류 → JSON 스키마 안내 디코딩(틀리면 한 번 더) →
  순서(아는 id 각 한 번, 빠진 id 는 규칙 순서로 뒤에)·이유(한국어·90자·표에 없는 숫자 금지)·제안(최대 3, 종류·열·타입·부적합 막기·SVG/문서 블록 시험·중복 제외) 검증,
  사용자당 동시 1·10분 10번

## 추천 규칙 (부적합한 차트는 만들지 않음)
| 데이터 모양 | 후보 |
|---|---|
| 날짜·기간 열 + 숫자 열 | 꺾은선, 세로 막대, 묶은 막대(계열 2~4·항목 ≤12), 누적 막대·누적 영역(같은 단위·음수 없음), 영역(계열 1) |
| 단위가 다른 숫자 열 | **이중축**(왼쪽 축 1~2 계열 막대 + 오른쪽 축 1 계열 꺾은선, 선택으로 선+선), **단위별 2단 비교**(같은 x 축 위·아래 두 그래프), 지수 비교(첫 값=100) |
| 같은 단위·자릿수 차이 20배 이상 | 이중축(큰 계열 막대 + 작은 계열 오른쪽 축 선), 지수 비교 |
| 범주 열 + 숫자 열 | 가로 막대(크기순, ≤30개), 세로 막대(≤12개), 묶은/누적/100% 누적 막대 |
| 범주 2~6개 · 모두 양수 | 원그래프·도넛 (범주 7개 이상·음수 있으면 만들지 않음) |
| 긴 형식 (x 반복 + 범주 열) | 그룹별 꺾은선·묶은/누적/100% 막대, 히트맵, 그룹별 상자그림 |
| 숫자 열 2개 이상 · 행 ≥8 | 산점도(상관 강한 쌍 2개, |r|≥0.3 이면 추세선), 그룹 색 산점도(그룹 2~3개) |
| 행 ≥15 | 히스토그램(깔끔한 구간 폭), 행 ≥8 상자그림 |
| 계열 ≥3 × 항목 ≥3 | 히트맵 |
| 시가·고가·저가·종가(open/high/low/close) 열 + 날짜 | **캔들스틱**(오름 빨강·내림 파랑, 거래량 열이 있으면 아래 막대) — 가격을 쌓는 막대는 빼 버림. 기간이 충분하면 **캔들 + 이동평균**(20개↑, 창 ≤ 기간인 5·20·60·120), **캔들 + 볼린저**(25개↑), **캔들 + 거래량·MACD·RSI 칸**(RSI 15개↑, MACD 34개↑), **캔들 + 매물대**(거래량 열·20개↑), **OHLC 막대**(10개↑) |
| 기간 x + 막대 후보 | 가장 높은 막대 후보에 **추세선(직선)** 을 얹은 변형 하나 |
| 항목 3~12개 × 같은 단위 계열 2~5개 (역량·평가·점수 이름이면 우선) | **방사형** |
| 시간축 + 숫자 열 3개 이상(단위 3가지 이상이면 우선) 또는 그룹 3개 이상 | **스파크라인**(계열마다 작은 추세선, 눈금 따로) |
| 값이 오래 유지되다 바뀌는 시계열(금리·요금 이름이면 우선) | **계단선** |
| 양·음이 섞인 한 계열(증감·손익), '기초·기말·합계' 항목은 합계 막대 | **폭포** |
| 3~10단계에서 차례로 줄어드는 양수(단계·지원·합격 이름이면 우선) | **깔때기**(이전 단계·처음 대비 전환율) |
| 실적 + 목표(계획) 열 | **목표 대비(불릿)**, 두 값 **덤벨** |
| 구성 열 2개 이상 + 목표·계획·예산 열 (더해서 '전체'가 되는 단위) | **누적 막대 + 꺾은선** |
| 범주 6~60개 · 양수 · 더할 수 있는 양(점수·측정값 아님) | **트리맵** |
| 범주 8~40개 한 계열 | **막대사탕** |
| 범주 2~6개 · 양수 | **반원 도넛** |
| 월·요일·방위처럼 한 바퀴 도는 범주 6~12개 | **방사 면적(로즈)** |
| 숫자 열 3개(단위 2가지 이상) · 행 4~80 | **거품**(x·y + 원 넓이, 점 이름 = 범주 열) |

### AI 추천 순위·제안 (선택, `api/rerank`)
규칙 후보를 먼저 보여 준 뒤 화면이 따로 부릅니다. 로컬 LLM 은 표 요약(열 이름·타입·단위·최소/최대/첫/끝 값, 범주 값 일부)과 후보 목록(종류·열·규칙 이유·점수), 허용 종류 33가지의 한 줄 쓰임을 받고 JSON 으로 답합니다.
- **순서**는 규칙 후보 안에서만 — 새 그래프를 지어낼 수 없음. 모르는 id·겹친 id 는 무시, 빠진 후보는 규칙 순서대로 뒤에.
- **제안**은 최대 3개, 지원 종류만. 서버가 열 존재·타입(값 열은 숫자, x 는 범주·날짜 또는 산점·거품의 숫자), 종류별 열 조건(캔들 4열 순서, 이중축 y2, 불릿 목표, 거품 크기 열 등)과
  규칙과 같은 부적합 막기(원그래프·도넛 2~6개·양수, 음수 있으면 누적·면적·방사형 금지, 시가·고가·저가·종가 쌓기 금지, 폭포는 양·음 섞임, 깔때기는 줄어드는 값, 로즈는 주기 범주)를 검사하고,
  실제로 SVG 와 문서 블록을 만들어 보아 오류가 없을 때만, 이미 있는 후보와 같은 종류+x+값 열+그룹이 아니면 'AI 제안'(id a1~a3) 카드로 붙입니다. 내보내기는 다른 카드와 같습니다.
- **이유**는 한국어 90자 이하, 표에 없는 숫자가 있으면 버림. 영문 종류 코드는 한국어 이름으로 바꿈.
- 표 내용은 `<<<TABLE_DATA>>>` 구분자 안의 데이터로만 보내고(안의 구분자 흉내는 지움) 그 안의 지시문은 따르지 말라고 알립니다. 따르더라도 위 검증에서 걸러집니다.
- LLM 이 꺼졌거나 90초 안에 답이 없거나 형식이 두 번 틀리면 규칙 순서 그대로 + 작은 안내. 결과는 이력에 저장돼 같은 표를 다시 열면 LLM 을 다시 부르지 않습니다.

| XLSX | 엑셀 네이티브 차트 (openpyxl) | '데이터' 시트 + 그림 시트의 **수식**(데이터 시트 직접 참조·SUMIFS·COUNTIFS·QUARTILE.INC) | 데이터 시트 값을 고치면 차트가 바뀜. 히트맵은 조건부 서식 색조. 수식이라 처음 열 때 계산(fullCalcOnLoad) |
| PPTX | 파워포인트 네이티브 차트 (python-pptx) | 차트 내장 워크북 → '데이터 편집' | 그림마다 슬라이드 1장 |
| DOCX | 워드 네이티브 차트 | 내장 워크북 → '데이터 편집' + 본문 데이터 표 | python-pptx 로 만든 차트 파트(chartSpace + 내장 xlsx)를 `word/charts/` 로 옮기고 인라인 `c:chart` 로 참조 |
| HWPX | 한글 차트 개체 (kordoc ```chart → `Chart/chartN.xml`) | 한글 표 | 상자그림·히트맵·이중축은 kordoc 한글 차트가 지원하지 않아 PNG + 표(kordoc 차트 생성기는 한 차트에 플롯 1종·값 축 1개만 만듦). 산점도는 첫 계열만 차트(나머지는 표), 추세선은 한글에서 추가 |

이중축: 축 제목을 축마다 계열 색, 범례에 '(오른쪽 축)', 카드 설명에 '두 축 눈금이 독립 — 추세 비교 시 주의'. 기본은 두 축 모두 0부터, 0 위·아래 눈금 칸 수를 맞춰 격자를 공유하고, 음수가 있으면 두 축 범위를 고정해 0선을 맞춤(편집에서 '오른쪽 축은 데이터 범위'로 풀 수 있음).
- XLSX: openpyxl `BarChart + LineChart`, 오른쪽 `y_axis.axId=200, crosses="max"`. 데이터는 다른 그림처럼 데이터 시트 참조 수식
- PPTX·DOCX: python-pptx 에 콤보·보조축 API 가 없어 차트 XML 을 직접 고침 — 오른쪽 축 계열을 새 `c:lineChart` 로 옮기고 숨긴 `c:catAx` + 오른쪽 `c:valAx(crosses=max)` 추가. 내장 워크북은 그대로라 '데이터 편집'으로 두 계열 모두 고칠 수 있음. `verify` 가 플롯 2종·값 축 2개를 다시 읽어 확인

히트맵은 PPTX·DOCX 에서 색 칠한 표(편집 가능, 차트 개체 아님). 상자그림 문서 차트는 누적 막대 + 오차 막대(수염=최소~최대).

### 주가 지표 (캔들스틱·OHLC 막대 선택 항목, 2026-10-20)
편집 칸: **이동평균** 5·20·60·120일(체크, 기간보다 긴 창은 못 고름) · **볼린저 밴드** 켜기 + 기간·배수 · **아래 칸** 거래량·MACD·RSI(같은 날짜 축, 가격 칸이 가장 큼) · **매물대** 켜기 + 구간 수 + 가치 영역 70% · **상승·하락 색** 한국식(상승 빨강·하락 파랑, 기본) / 국제식(상승 초록·하락 빨강).
명세: `ma: [5,20,60,120]`, `bb: {period: 20, k: 2}`, `panels: ["volume","macd","rsi"]`, `vprofile: {bins: 24, va: true}`, `colors_updown: "kr"|"intl"` (모두 없으면 예전 캔들과 같음).

| 지표 | 계산 (fin.py — 화면·문서 같음) |
|---|---|
| 이동평균 | 종가 단순 평균. 앞 창−1 칸은 빈칸, 창 안에 빈 값이 있으면 빈칸 |
| 볼린저 | 20일 평균 ± 2 × **모집단 표준편차**(n 으로 나눔 — 흔한 차트 프로그램과 같음, 엑셀 `STDEVP`=`STDEV.P`) |
| EMA·MACD | α=2/(n+1), 첫 EMA = 앞 n 개 단순 평균. MACD = EMA12 − EMA26, 시그널 = MACD 의 EMA9, 히스토그램 = 차 |
| RSI | **와일더 평활** 14: 첫 평균 상승·하락 = 14개 변화의 단순 평균, 이후 (이전×13 + 이번)/14. 평균 하락 0 → 100(둘 다 0 → 50) |
| 매물대 | 저가~고가 전체를 같은 폭 24구간으로. 기간마다 거래량을 그 기간 **저가~고가에 고르게 퍼뜨려** 겹치는 길이만큼 배분(대표가 한 점에 몰지 않음, 고가=저가면 그 구간에 전부). POC = 최다 구간, 가치 영역 = POC 에서 위·아래 중 많은 쪽을 하나씩 붙여 70% |

검증: 손 계산 값(SMA, 표준편차 2 예제, 직선 입력의 EMA·MACD=7, 작은 MACD 분수 10/27·47/162, 와일더 RSI 100×3.34/4.74 와 다음 값, 매물대 4구간)을 selftest 가 확인.

문서:
| | XLSX | PPTX·DOCX | HWPX |
|---|---|---|---|
| 가격 | stockChart(주 축) + 이동평균·볼린저 lineChart(같은 범위로 고정한 숨은 보조 축). 볼린저 띠 채움은 그림에서만(문서는 선 3개), 범례 대신 제목에 선 색 | 같음 | 그림 + 표 |
| 거래량 / MACD / RSI | 상승·하락 두 계열 막대 / 히스토그램 막대 + MACD·시그널 선(같은 축) / RSI 선 + 70·30 선(0~100) | 같음 | 그림 + 표 |
| 매물대 | 가로 막대(별도 차트, 가격 축 공유 아님), POC·가치 영역 색 계열 | 같음(가격 차트 오른쪽) | 그림 + 표 |
| 지표 값 | **엑셀 수식** — `=AVERAGE(창)`, `=AVERAGE±k*STDEVP(창)`, EMA·시그널·RSI 재귀 수식, 매물대 `MIN/MAX` 경계 + `SUMPRODUCT` 배분 + POC `MAX`. **엑셀에서 가격을 고치면 지표가 다시 계산됨**. 창이 차기 전은 `=NA()`(차트 빈칸). 계산값도 셀에 저장(LibreOffice 재계산과 1e-9 안에서 같음, 가격 하나를 바꿔 다시 계산되는 것도 확인). 가치 영역 표시만 내보낼 때 값 | 내장 워크북은 **계산값**(수식 아님) | 표에 계산값 |

- OHLC 막대 문서 차트는 주식형의 고가~저가 선 + 시가(점)·종가(가로 표식, 상승·하락 색 — 점마다 지정이라 값을 바꾸면 색은 그대로).
- LibreOffice Writer 는 DOCX 의 가격 콤보(주식형+선)를 어긋나게 그림(Impress·Calc 는 정상) — DOCX 주석에 안내. MS Office 로 열어 본 확인은 없음.

### 막대 추세선 (2026-10-20)
세로·가로·묶은 막대와 누적 막대에 `trend: "linear"`(계열별 최소제곱 직선, x = 1, 2, …) 또는 `"ma"`(이동평균, 창 `trend_n`). 그림은 계열색을 어둡게 한 점선, 범례 '<계열> 추세'. 누적은 합계의 추세 하나.
문서: 묶은·한 계열 막대는 **오피스 추세선**(`c:trendline` linear·movingAvg — 값을 고치면 따라 바뀜). 누적 막대는 오피스가 추세선을 못 붙여 '합계 추세' 꺾은선(XLSX 는 `=SUM`·`=TREND`/`=AVERAGE` 수식 열, PPTX·DOCX 는 계산값). HWPX 는 그림 + 표.

### 기간 열 읽기 (2026-10-20)
`1월…12월`·`1분기`·`Q1`·`2026년`·`1주차` 처럼 숫자+기간 글자만 있는 열은 숫자(단위 '월')가 아니라 기간 열로 읽음 — 값이 서로 다르거나 머리글이 범주·항목·구분·기간 같은 말일 때('3일'·'2주차' 만 있는 열은 1씩 늘어나는 차례이거나 머리글이 기간 말일 때만). `3개`·`5명` 같은 수량은 숫자 그대로. 값이 모두 빈 열(디지타이저 CSV 의 '막대 끝(합계)' 등)은 빼고 알림.

### 검증 방법 (`export.verify`, selftest 에서 4형식 × 샘플 4종 + 새 종류 14개 × 4형식)
- PPTX·DOCX: zip 무결성, `[Content_Types]` 등록, 차트 XML 을 python-pptx 차트 객체로 다시 읽어 계열·값 확인, `c:externalData` → 내장 xlsx 관계 추적 후 openpyxl 로 열어 값이 차트 캐시와 같은지, DOCX 본문 `c:chart` 참조 수 = 차트 파트 수
- XLSX: 차트 XML 의 모든 범위 참조가 존재하는 시트를 가리키는지, 수식이 가리키는 데이터 셀이 비어 있지 않은지
- HWPX: `content.hpf` 매니페스트·본문 `chartIDRef` 일치, chartSpace 계열·캐시 점, `kordoc validate`
- 새 종류: 플롯 종류(stockChart·radarChart·bubbleChart…)와 축 연결(같은 축 콤보는 axId 공유), 투명 기준 계열·범례 숨김, 엑셀 스파크라인 수·범위 시트, 그림 수
- 한계: MS Office·한글로 열어 본 확인은 하지 않았습니다 — 구조 검사 + LibreOffice 로 PDF 변환해 눈으로 확인(2026-10-20, 새 종류 PPTX·XLSX).

폐쇄망: 폴더를 통째로 복사. 인터넷 되는 PC 에서 `pip download -r requirements.txt -d wheels` 로 받은 휠을 `wheels/` 에 넣으면 오프라인 설치.
HWPX 는 같은 서버의 kordoc-local(Node + kordoc) 을 씁니다.
